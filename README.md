## 📖 О проекте

**MonitorPlus** — специализированное WPF-приложение, созданное для инженеров КИПиА, операторов котельных, диспетчеров и специалистов тепловых сетей. Приложение обеспечивает наглядный оперативный контроль параметров оборудования в реальном времени, избавляя от необходимости работать с тяжёлым интерфейсом базового клиента.

## ✨ Основные возможности

### 🎛 1. Дашборд объектов и экспресс-мониторинг
* **Masonry Layout:** Карточки узлов учёта автоматически и компактно организуются в адаптивную сетку.
* **Цветовая индикация состояний:**
  * 🟢 **Зелёный** — параметры в пределах нормы.
  * 🟡 **Оранжевый** — сбой опроса или ошибка связи.
  * 🔴 **Красный** — зафиксировано нарушение технологических границ или температурного графика.
* **Контролируемые параметры:**
  * Температуры подачи и обратки (T1, T2)
  * Давления в трубопроводах (P1, P2)
  * Объёмный и массовый расходы (V1, V2, M1, M2)
  * Тепловая энергия (Q)
* **Индивидуальный масштаб:** Удобный ползунок регулировки размера карточек под любое разрешение экрана без искажения общего интерфейса программы.

### 💧 2. Специализированный модуль «Подпитка» (V1 / M1)
* Выделенный экран для оперативного контроля расхода подпиточной воды.
* Скрываемая боковая панель с быстрым поиском, фильтрами по объектам и множественным выбором точек.
* Расчёт и сопоставление объёмов в 4 временных срезах:
  * **Отчётный период** — закрытый месячный срез с 25 по 24 число.
  * **Вчера** — закрытые расчётные сутки из архива ЛЭРС.
  * **Сегодня** — накопленный объём с 00:00 до текущего часа.
  * **Прошлый час** — оперативный часовой расход (м³/ч).
* Поддержка всех вариантов параметров подпитки в системе ЛЭРС (V_in, V_mu, M_mu, V_delta, V1, M1).

### 📈 3. Температурные графики и уставки
* Индивидуальная и групповая настройка граничных допусков (Tmin/Tmax, Pmin/Pmax и др.).
* Задание таблицы температурного графика качественного регулирования теплоносителя в зависимости от температуры наружного воздуха.
* Автоматическое периодическое чтение текущей температуры на улице с опорного датчика.

### ⚡ 4. Защита каналов связи (PollCoordinator)
* Интеллектуальный координатор сетевых запросов: не перегружает каналы связи и GSM/CSD-модемы одновременными запросами.
* Кэширование свежих записей для снижения нагрузки на сервер базы данных.
* Настраиваемый фоновый автоопрос (интервал от 1 до 60 минут) и кнопка мгновенного принудительного обновления.

### 🎨 5. Удобство и персонализация
* Светлая, тёмная и автоматическая темы оформления (переключение по расписанию день/ночь).
* Безопасное локальное сохранение учётных данных и профилей настроек пользователя.

## 🚀 Быстрый старт

### Требования
* ОС Windows 10 / 11
* Установленный .NET Runtime
* Доступ к серверу ЛЭРС УЧЁТ (IP/хост, порт API, логин и пароль)

### Установка и сборка
1. Склонируйте репозиторий:
   ```bash
   git clone [https://github.com/](https://github.com/)<ваш-аккаунт>/<имя-репозитория>.git
   ```
2. Откройте решение в **Visual Studio** или скомпилируйте через CLI:
   ```bash
   dotnet build -c Release
   ```
3. Запустите приложение, укажите данные сервера и нажмите **«Подключиться»**.
